网络通讯

  1. 终端 cmd(windows的)
  2. 进入方法：win+r 输入cmd

常用命令：

​ whomi 我是谁 （当前用户名）

​ ipconfig 查看本机IP地址

​ ping 地址 测试能不能联通对方

​ netstat -ano 查看本机开了那些端口

​ cd 目录 切换目录

​ dir 列出当前目录的内容

​ cla 清除屏幕

  1. 怎么读命令输出（实在不会丢给ai）

ip地址基础

2.1 ip地址的作用

简单理解，用来定位/查询的门牌号

样子：

192.168.1.100 最常见的ipv4 格式：4组数字用点隔开，每组0·~255

2408:8207:xxxx ipv6 格式：更长，用冒号隔开

2.2 公网IP和内网ip

公网：全球唯一，均可访问

内网：只在内部网络有效，网面默认访问不到

判断公网和内网

开头

  1. 大内网（大公司大机构常用）

172.16.~172.31. 中等内网

192.168. 家用路由器或小企业内网

端口与服务

3.1 端口是什么

类比

IP 酒店地址

端口 酒店的房间号

服务（程序） 住在房间的客人

端口号的范围 0~65535

3.2 常见端口

端口 服务 用处
80 HTTP 网站访问
443 HTTPS 加密的网站访问（现在的大多数网站）
22 ssh 远程登陆linux服务器
3306 MySQL MySQL数据库服务
21 FTP 文件传输
53 DNS 域名解析
8080 备选web/代理 常见代替80的端口

3.3 端口开放=服务对外=安全暴露面

端口可以理解成服务的入口 入口越多越危险

接手服务器要查看它开了哪些端口

客户端与服务端的关系

客户端发送请求，服务端提供服务

一次完整的访问：

客户端发送请求 >> 服务端收到后返回网页 >> 浏览器显示网页

一般攻击者，攻击的对象就是服务端

域名，DNS与解析过程

5.1 为什么要有域名

域名：方便人类记住（ip难记）

例子：www.baidu.com

域名从右往左

部分 层级 举例
顶级域名 最后一级 .com .cn .org
二级域名 中间 baidu
主机名 最前面 www

5.2 DNS是什么

DNS （域名系统）

输入域名 >> DNS查询>>返回IP>> 打开网页

内网外网与网络隔离

6.1 内网怎么上网：NAT

NAT:路由器把内网数据换成自己公网IP发出去的数据

6.2 物理隔离和逻辑隔离

物理隔离：两个网络之间完全没有物理连接

逻辑隔离：物理上连着，用技术手段来规定哪些能访问

代理和隧道（概念）

7.1 代理

简单理解：代理就是帮你转交请求的中间人。

概念 说明
正向代理 你请求代理，代理替你访问网站（你躲在代理后面）
反向代理 客户请求代理，代理吧亲环球转交给后面的真实服务器（目标躲在代理后面）

7.2 隧道

把一种流量“打包”进另一种流量里
